Collect results from students' devices

Without a backend, each result stays in the browser where the exam was taken. Ask students to press Download my result (CSV) after submitting and send you the file. Import all the files here to combine them into one list, then export.

Attempts on this device

Useful on a shared lab computer. Resetting a student number removes its attempts from this browser only, which gives that student their attempts again here.

Make a new PIN

Type a new PIN (10 or more characters is best). Copy the code it produces into instructorPinHash in config.js, then upload that file.
